# Android Basics with Compose – Unidad 4

Ejercicios de la **Unidad 4: Navegación y arquitectura de la app** del curso Desarrollo de Sistemas Móviles (UNMSM, 2026-2).

## Ruta 1 – Componentes de arquitectura (`Ruta1_ArquitecturaEstado`)

Ciclo de vida de las actividades, ViewModel, estado en Compose y el patrón de flujo de datos unidireccional.

| Proyecto | Codelab |
|---|---|
| `DessertClicker` | Stages of the Activity lifecycle · Practice: Add a ViewModel to Dessert Clicker |
| `Unscramble` | ViewModel and State in Compose · Write unit tests to test the ViewModel |

## Ruta 2 – Navegación en Jetpack Compose (`Ruta2_Navegacion`)

Componente Navigation: rutas, NavHost, NavController y paso de datos entre pantallas.

| Proyecto | Codelab |
|---|---|
| `Cupcake` | Navigate between screens with Compose · Test the Cupcake app |
| `LunchTray` | Practice: Add navigation |

## Ruta 3 – Diseños adaptables (`Ruta3_DisenoAdaptable`)

Clases de tamaño de ventana, navegación dinámica y diseño lista-detalle para pantallas grandes.

| Proyecto | Codelab |
|---|---|
| `Reply` | Build an adaptive app with dynamic navigation · Build an app with an adaptive layout |
| `Sports` | Practice: Build Sports app |
| `MyCity` | Project: Create a My City app — app propia "Mi Lima", recomendaciones por categorias |
